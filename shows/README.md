# The shows' notebooks

One file per idle show (`games/love/home/<show>.lua`): what the last review found, the plan, what was done, and
the ideas not done yet. Step 4 of [SHOWS_PIPELINE.md](../SHOWS_PIPELINE.md); the rules are
[SHOWS_BLUEPRINT.md](../SHOWS_BLUEPRINT.md).

A notebook has these sections, newest round first:

```
# <Show>

## Round N (date): what this round set out to do

### Measured   tools/show_review.py's table, before -> after (stale, beats/m, still, cover, song loops)
### Scorecard  the craft scorecard per scene, 0-3 on S H L A D C G F M X (SHOWS_PIPELINE.md), before -> after
### Done       what changed, scene by scene (story, art, music, sounds)
### Checked    the cabinet's fps per scene; anything seen by eye that the numbers miss

## Ideas       not done yet, each tagged with what it fixes (S/H/L/A/D/C/G/F/M/X) and its cost (S/M/L)
```

Notebooks: [texas](texas.md), [longhorns](longhorns.md), [summer](summer.md), [space](space.md) (Mission Control), [thanksgiving](thanksgiving.md), [christmas](christmas.md).
